# Live-pilot decisions — not approved / not launched

The local demo establishes a connected transaction and reviewable operations UI. It does not establish operating authority, willingness to pay, payment readiness, field connectivity or commercial outcomes.

| Decision | Evidence or approval required before a live pilot |
|---|---|
| Operating authority and site | Named CG sponsor, authorized zone boundaries, signage permission, operator responsibilities |
| Tariffs and currency | Approved amount, currency, rounding, taxes, price display and change authority |
| Validity | Approved start rule, delayed-payment treatment, grace period, maximum duration, expiry and extensions |
| Payments | Selected channels, merchant account ownership, provider access and documented authentication/event verification |
| Reconciliation | Settlement/remittance format, matching rules, exception ownership, reporting and daily close sign-off |
| Cash | Explicit yes/no decision; if enabled, separate numbered receipts, staff attribution, shift totals and reconciliation |
| Disputes/refunds | Named owner, approval limits, evidence requirements, provider process and driver communication |
| Privacy/retention | Lawful collection/notice, minimal fields, access policy, retention/deletion schedule and incident response |
| Connectivity | On-site coverage test, offline escalation procedure and prohibition on offline payment confirmation |
| People/training | Individual staff identities, assigned zones, training and manager handover |
| Reliability | TLS, secrets, durable backups/restore drill, observability, provider retry recovery and rate limits |
| Acceptance | Agreed test sessions, quote accuracy, retrieval success, event duplicate handling, staff lookup latency and reconciliation checks |
| Commercial terms | Buyer, pilot fee, delivery costs, duration, support boundary and continuation decision |

Proposed acceptance exercise: create driver and assisted sessions on independent authorized devices; compare stored records with provider test events; test failures/delays/duplicates; review a daily close and settlement exceptions; conduct a controlled connectivity outage; rehearse a dispute. Set numerical success targets with CG before field testing. Active paid sessions must never be represented as measured parking occupancy.

Deferred: live provider adapter/webhooks, settlement imports/matching, cash, extensions, camera/ANPR/gates, automatic enforcement, marketplace/reservations, AI analytics, offline write synchronization, issue resolution and multilingual localization. No claims about customer traction, revenue impact, traffic/ad exposure or live readiness are made.
